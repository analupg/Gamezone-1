CONHEÇA O PROJETO

O que é o GameZone?

Uma aplicação desenvolvida para reunir informações sobre jogos em uma interface organizada, intuitiva e agradável.

🎮

Catálogo de jogos

Permite explorar jogos e consultar informações como descrição, gênero, desenvolvedor e plataformas.

🚀

Lançamentos

Apresenta uma seleção de jogos em uma área destinada aos lançamentos do aplicativo.

💖

Favoritos

Oferece uma área para consultar os jogos marcados como favoritos durante o uso do aplicativo.

💡

Objetivo do projeto

O GameZone tem como objetivo facilitar a descoberta e a consulta de informações sobre jogos por meio de uma interface simples e organizada.

ARMAZENAMENTO DE DADOS

Banco de dados com Supabase

Aprenda a utilizar o Supabase para armazenar e consultar as informações dos jogos do GameZone. O catálogo poderá ser consultado sem exigir login dos usuários.

💡

Importante

Esta documentação apresenta uma proposta de integração. Para funcionar, o banco precisa ser criado e conectado ao projeto Flutter. O catálogo pode ser público sem exigir cadastro ou confirmação de e-mail no aplicativo, desde que as permissões sejam configuradas corretamente.

01

Entenda o Supabase

Organização das informações

O Supabase oferece um banco de dados PostgreSQL na nuvem. No GameZone, ele poderá guardar nome, gênero, descrição, desenvolvedor, plataformas e nota dos jogos.

Uma tabela inicial poderá utilizar esta estrutura:

Campo Tipo Finalidade
idbigintIdentificador do jogo
nametextNome do jogo
genretextGênero do jogo
descriptiontextDescrição
developertextDesenvolvedor
platformstextPlataformas compatíveis
ratingnumericNota do jogo
02

Crie o projeto no Supabase

Configuração inicial

  1. Acesse o painel do Supabase .
  2. Entre na sua conta e crie um projeto.
  3. Escolha um nome para o projeto GameZone.
  4. Configure a senha do banco e a região.
  5. Aguarde a criação do banco.
  6. Abra o SQL Editor para executar o próximo código.
03

Crie a tabela de jogos

SQL Editor

Execute o SQL abaixo para criar a tabela e permitir a leitura pública do catálogo. A política não permite inserir, editar ou excluir registros publicamente. 

create table public.games (
    id bigint generated by default as identity primary key,
    name text not null,
    genre text,
    description text,
    developer text,
    platforms text,
    release_date text,
    image_url text,
    website_url text,
    rating numeric default 0
);

alter table public.games enable row level security;

grant select on public.games to anon;

create policy "Permitir leitura publica dos jogos"
on public.games
for select
to anon
using (true);

Atenção: não exponha a chave secreta ou a chave service_role no aplicativo. Mantenha a proteção RLS ativa.

04

Adicione um jogo de exemplo

Inserindo informações no banco

Execute este comando no SQL Editor:

insert into public.games (
    name,
    genre,
    description,
    developer,
    platforms,
    rating
)
values (
    'Project Makeover',
    'Moda e beleza',
    'Um jogo de transformação e estilo.',
    'Magic Tavern',
    'Android e iOS',
    4.7
);

Cadastre os outros jogos seguindo o mesmo formato.

05

Obtenha as credenciais

Conectando o aplicativo

  1. Abra as configurações do projeto no Supabase.
  2. Localize a URL do projeto e a chave publicável.
  3. Guarde as informações para configurar o Flutter.

Use somente a chave pública apropriada para o cliente. A segurança deve ser garantida pelas políticas RLS.

06

Instale a biblioteca do Supabase

Terminal do Flutter

Com o projeto aberto no Android Studio, execute:

flutter pub add supabase_flutter
07

Configure a conexão no Flutter

Arquivo: main.dart

Inicialize o Supabase antes de executar o aplicativo. Substitua os valores de exemplo pelas credenciais do projeto. 

import 'package:flutter/material.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Supabase.initialize(
    url: 'SUA_URL_DO_SUPABASE',
    publishableKey: 'SUA_CHAVE_PUBLICA',
  );

  runApp(const GameZoneApp());
}

Adapte o trecho ao main.dart existente. Preserve o restante do aplicativo e não crie uma segunda função main().

08

Consulte os jogos cadastrados

Exemplo de consulta

final jogos = await Supabase.instance.client
    .from('games')
    .select();

print(jogos);

A consulta retorna os dados. Para exibi-los no catálogo, converta os registros para o modelo usado pelo GameZone.

09

Teste a integração

Verificando o funcionamento

  • Execute o aplicativo Flutter.
  • Confira se a consulta retorna os jogos cadastrados.
  • Verifique se os erros de conexão são tratados.
  • Teste o catálogo sem login.
  • Confirme que a escrita não está liberada publicamente.
10

Boas práticas de segurança

Organização e manutenção

  • Mantenha a proteção RLS ativada.
  • Libere apenas as operações necessárias.
  • Não coloque chaves secretas no código do aplicativo.
  • Trate falhas de rede e resultados vazios.
  • Teste as permissões antes de publicar o aplicativo.
