> **GameZone** é um aplicativo mobile e web para explorar, catalogar e gerenciar seus jogos favoritos, com autenticação de usuários e sincronização em tempo real via **Supabase**.

---

## 🚀 Funcionalidades

- 🔐 **Autenticação de Usuários**: Cadastro e Login seguros utilizando Supabase Auth.
- 🎮 **Catálogo Completo de Jogos**: Navegação por jogos em destaque, categorias e gêneros (Ação, RPG, Aventura, etc.).
- 🔍 **Busca & Filtros**: Sistema de pesquisa por nome e filtragem por categorias em tempo real.
- ❤️ **Gerenciamento de Favoritos**: Sincronização dos jogos favoritados diretamente no banco de dados na nuvem para cada usuário.
- 📖 **Detalhes do Jogo**: Visualização de sinopse, nota/avaliação, desenvolvedora, plataformas disponíveis, data de lançamento e link para o site oficial.
- 👤 **Perfil do Usuário**: Exibição das informações da conta, estatísticas de jogos salvos e opção de logout.
- 🎨 **Interface Moderna**: UI/UX responsiva construída com Material Design 3 e gradientes personalizados.

---

## 📱 Navegação do App

1. **Início (`HomePage`)**: Apresenta os jogos mais populares, destaques e novidades.
2. **Explorar (`ExplorePage`)**: Campo de busca interativo e seletores de gênero.
3. **Lançamentos (`ReleasesPage`)**: Lista organizada dos lançamentos mais recentes.
4. **Favoritos (`FavoritesPage`)**: Coleção pessoal de jogos salvos pelo usuário conectado.
5. **Perfil (`ProfilePage`)**: Gerenciamento da conta do usuário logado.

## 🗄️ Estrutura do Banco de Dados (Supabase SQL)

Se você desejar rodar o projeto no seu próprio ambiente do Supabase, execute os seguintes comandos no **SQL Editor** do seu painel Supabase:

```sql
-- 1. Tabela de Perfis de Usuários
create table if not exists public.profiles (
  id uuid references auth.users on delete cascade primary key,
  name text,
  email text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Habilitar RLS em Profiles
alter table public.profiles enable row level security;

create policy "Usuários podem ver e editar o próprio perfil"
  on public.profiles for all
  using (auth.uid() = id);

-- 2. Tabela de Favoritos
create table if not exists public.favorites (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users on delete cascade not null,
  game_id integer not null,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  unique(user_id, game_id)
);

-- Habilitar RLS em Favorites
alter table public.favorites enable row level security;

create policy "Usuários gerenciam apenas seus próprios favoritos"
  on public.favorites for all
  using (auth.uid() = user_id);
```

## ⚙️ Configuração do Projeto

### Pré-requisitos

- **Flutter SDK** (versão `>= 3.4.0`)
- **Git**
- Uma conta no **[Supabase](https://supabase.com/)**

### Passos para Instalação

1. **Clonar o Repositório**:
   ```bash
   git clone https://github.com/SEU-USUARIO/gamezone.git
   cd gamezone
   ```

2. **Instalar as Dependências**:
   ```bash
   flutter pub get
   ```

3. **Configurar o Supabase**:
   No arquivo `lib/main.dart`, substitua a URL e a Publishable Key pelas credenciais do seu projeto Supabase:
   ```dart
   const String supabaseUrl = 'YOUR_SUPABASE_URL';
   const String supabasePublishableKey = 'YOUR_SUPABASE_PUBLISHABLE_KEY';
   ```

4. **Executar a Aplicação**:
   ```bash
   # Para rodar no navegador (Web)
   flutter run -d chrome

   # Para rodar no Emulador/Dispositivo Android
   flutter run
   ```
